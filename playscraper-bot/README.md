# Playscraper Bot

![Reddit](https://img.shields.io/badge/Reddit-FF4500?style=for-the-badge)
![Devvit](https://img.shields.io/badge/Devvit-FF4500?style=for-the-badge)
![Category](https://img.shields.io/badge/Category-Moderation-blue?style=for-the-badge)

Playscraper Bot is a professional moderator utility that leverages advanced AI to extract and summarize metadata from application links. It provides standardized, informative headers for mobile applications and open-source projects to assist moderators in verifying shared content.

## Features
- **Metadata Extraction**: Identifies and processes links from the Google Play Store and GitHub repositories.
- **Smart Summaries**: Uses AI to automatically provide metadata and description parsing.
- **Automated Processing**: Instantly detects and summarizes links in new posts automatically.
- **Queue Synchronization**: Intelligently waits for post approvals before generating automated summaries to keep subreddits clean.
- **Manual Trigger**: Supports manual overrides and "On-Demand" scans via the native Reddit Post Menu.

## Install / Use
1. Install **Playscraper Bot** via the App Directory.
2. Once installed, it will automatically process new posts as they are approved.
3. Moderators can also trigger manual scans on any post using the Mod actions menu.
